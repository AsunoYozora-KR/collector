# 인물 카드첩

나 혼자 쓰는 카드 보관 앱. 아이패드 가로 화면 기준.

- 태그 여러 개로 좁혀 보기 (고른 태그를 모두 가진 카드만)
- 이름 검색 (초성 검색 가능)
- 정렬: 이름순·이름 역순(영어 → 한글 → 그 외), 최근 추가순·오래된 추가순
- 대표 사진 + 기본 정보 + 사진이 붙는 구분 최대 9개
- 옆으로 밀어서 다음 카드
- 백업 파일 내보내기 / 가져오기
- 비공개 레포로 기기 간 동기화 (암호화)

## 데이터는 어디에 저장되나

카드와 사진은 **이 레포가 아니라, 앱을 연 기기의 브라우저 안**(IndexedDB)에 저장된다.
이 레포에는 앱 코드만 있고, 개인 정보는 하나도 들어 있지 않다.

동기화를 켜면 별도의 **비공개 레포**(예: `collector-data`)가 원본이 된다.
- `meta.json` — 비밀번호 확인용 정보 (카드 내용 없음)
- `cards/<id>.bin` — 카드 하나당 파일 하나, 기기에서 AES-GCM으로 암호화한 뒤 올림
- `images/<id>.bin` — 사진 한 장당 파일 하나, 암호화
- 열쇠(Fine-grained token, Contents: Read and write)와 암호 키는 각 기기 안에만 저장된다.

## 쓰는 법

1. GitHub Pages로 배포한다 (Settings → Pages → Branch: `main`, 폴더 `/ (root)`).
2. 아이패드·아이폰 사파리에서 배포 주소를 연다.
3. 공유 버튼 → "홈 화면에 추가". 이후 홈 화면 아이콘으로 연다.
